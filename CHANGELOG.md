# Change Log

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](http://keepachangelog.com/)
and this project adheres to [Semantic Versioning](http://semver.org/).


## [Unreleased]

### Changed
- Update development dependencies to verify compatibility with current LangChain packages:
  `@langchain/google-genai` 2.3.x, `@langchain/mcp-adapters` 1.1.x, and `langchain` 1.5.x.
- Move `@langchain/google-genai` to `peerDependencies` so consumers can keep using compatible
  older versions while this project tests against the latest version in development.
- Keep the package runtime requirement at Node.js 18+ for compatibility with older supported
  `@langchain/google-genai` versions.
- Simplify package exports to expose only the main `ChatGoogleGenerativeAIEx` entrypoint.
- Align `main`, `module`, and `exports` fields with the files generated by `tsup`.
- Refresh the README usage example to match current LangChain.js MCP patterns, including
  plain message objects, explicit stdio transport, standardized content blocks, and reliable
  MCP client cleanup.
- Clarify in the README that this package targets `@langchain/google-genai` users, while new
  Google Gemini integrations should consider LangChain's newer `@langchain/google` package.
- Replace the simple test with a local smoke test that does not require external MCP servers or
  live Gemini API access.

### Fixed
- Avoid leaving `required: undefined` on transformed object schemas after invalid required
  fields are removed.
